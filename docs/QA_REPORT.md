## Defects found and fixed

- Fast browser taps did not always deliver `onPressIn`: zero press delay plus deduplicated press fallback; browser and native-renderer regression coverage.
- Korean ghost text removed incomplete syllables: physical-keystroke segmentation now keeps the remaining target and separately shows composition; tested at partial syllable boundaries.
- Sentence learning was unreachable: Home now exposes Words/Short sentences and preserves kind on entry.
- Slow clean Speed sessions incorrectly received S: result rank now aggregates actual answer ranks through tuning; RED→GREEN regression.
- Response times were quantized to500ms: monotonic exact foreground timer, pause/resume and sub500ms regression. Active study time flushes completed short answers.
- Returning from sessions accumulated duplicate Home routes: entry now replaces the single active practice screen; repeated offline browser journeys pass.
- Rain final score was not retained: persisted final/personal-best scores with regression test.
- Native service shells lacked concrete SDK wiring: lazy AdMob/RevenueCat bridges added, including stale-ad and revoked-entitlement regressions.
- Incomplete dependency peers/types: Expo Asset, System UI and SDK-matched Jest types installed; doctor now passes18/18.
- Saved progress validation and per-tick write amplification: strict profile validation, transactional SQL projection and changed-row writes; corruption and rollback tests preserve existing data.
